# Sistem-panen-shareefa
## Deskripsi Singkat
Program Python sederhana untuk menghitung total hasil panen dan menghitung nilai setelah diskon. Proyek ini dibuat untuk latihan Git dan GitHub.
## Cara Menjalankan Program
Pastikan Python sudah terpasang di komputer. Unduh proyek ini dengan perintah git clone, lalu masuk ke folder proyek dan jalankan berkas panen.py dengan perintah python panen.py di terminal. Program akan menampilkan total hasil panen beserta nilai setelah diskon.
